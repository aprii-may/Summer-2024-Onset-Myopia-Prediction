# Abstract:

Myopia, or nearsightedness, is a prevalent eye-focusing disorder that often begins in childhood. [1] This study uses data from children enrolled in the Orinda Longitudinal Study of Myopia (OLSM) between 1989 and 1996 to develop a machine learning model for predicting juvenile myopia onset and identifying key contributing features. We trained models using random forest (RF), Support Vector Machine (SVM), and extreme gradient boosting (XGBoost), and evaluated their performance by plotting ROC curves and calculating the AUC. Among the three models, the XGBoost model demonstrated the highest accuracy. Feature importance analysis of the XGBoost model highlighted the spherical equivalent of the participants' refractive error and the number of sports hours as the most significant factors influencing myopia onset.
